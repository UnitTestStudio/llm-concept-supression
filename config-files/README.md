# Configuration files

This directory contains small, review-facing configuration files for the
Unlearning to Rest model construction pipeline.

The final study configuration is `chair-3B-hybrid-config.json`. It records the
base model, concept definition, example file, activation cache path, pruning
settings, test settings, and output path used for the hybrid 3B model.

Large generated files referenced by configs, including activation caches and
model checkpoints, are not stored in Git.
